# Nimin Fetish Fantasy — Electron/TypeScript Port

Nimin was a gem. A quirky, deeply personal Flash game that deserved to 
survive Flash's death. It didn't get that chance — until now.

This is a faithful, open source port of Nimin v1, built from the original 
ActionScript 3 source code by **Xadera**, converted line by line into a 
modern Electron + TypeScript desktop app. No shortcuts. No reimagining. 
No monetization. Just the game, preserved and playable, the way it was 
meant to be experienced — for free, forever.

## Credit
All original game content, writing, and design belong to **Xadera**.  
This port exists solely to preserve their work for future generations.  
If Xadera wishes to be involved or has concerns, please reach out.

## Status
Core port is complete. Bug fixing and playtesting are ongoing.  
If something doesn't match the original Flash behavior, that's a bug — 
open an Issue.
